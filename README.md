# Sheet Music Browser

Sheet Music Browser is a lightweight program for viewing PNG files as a replacement for paper sheet music.

## Installation

No install required, however you will need pillow and tkinter. tkinter is included with Python, but for pillow: use [pip](https://pip.pypa.io/en/stable/).

```bash
py -m pip install pillow
```

## Usage

The program is entirely contained in the GUI and should be fairly straight forward to navigate. Click 'Open File' to open a PNG file. The image will open in a new, maximized window. Multiple windows can be opened this way. There is also a text box where notes on the piece can be entered. The entered text can be saved to a text file on the local system. Also the text box can be cleared with a 'Clear Text' button.
